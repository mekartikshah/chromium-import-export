## Short description

Export and import your browsing history and bookmarks between Chromium-based browsers.

## Full description

Chrome Toolkit lets you export your browsing history and bookmarks to JSON files
and import them back, on this browser or any other Chromium-based browser
(Chrome, Edge, Brave, Opera).

Features:
- Export bookmarks as JSON
- Export up to 100,000 history entries
- Import bookmarks and history from JSON files
- Imports run in the background - you can close the popup while they finish
- Everything runs locally; no data leaves your browser

History import accepts:
- History files exported by this extension
- Google Takeout "Browser History" files
- JSON arrays of history items, or files in {"urls": [...]} format

Note: Chrome's API does not allow extensions to restore original visit
timestamps. Imported history entries are added with the current date. Titles
and visit counts are also not preserved.

Privacy:
- Runs completely locally; no servers, no tracking, no analytics
- Open source - you can review the code
